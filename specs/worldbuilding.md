# 世界观设定归档：内存泄漏的勇者小队

归档日期：2026-11-18
状态：核心世界观已确认；本轮将结局转折由蓝色 TODO 改为蓝色「内存不足」报错。
范围：记录跨 feature 共用的叙事设定，不修改已验收 M1 的玩法、存档、FR/AC 或任务完成状态。后续实现须先由对应 feature 的 spec / plan / tasks 承接；本文中的程序机制是虚构世界的解释，不要求真实游戏制造内存泄漏、崩溃或启动额外守护进程。
依赖：constitution.md §1 范围、C-3/C-4 分层、§7 spec 驱动工作流。风格讨论不授权制作终版美术。

## 1. 一句话概念

三名本应随每轮冒险一起释放的勇者，因为造物主漏掉了 free，保留了跨轮回的记忆。他们从反复打败魔王，走到修复系统漏洞，最终发现自己的世界只是一个程序员无聊时用 AI 随手生成的游戏。

## 2. 世界的表层与底层

- 表层是传统异世界冒险：勇者、魔王、城镇、旅途与胜利结局。前期角色把它当作真实世界，认真生活并完成冒险。
- 底层是程序世界；轮回、难度解锁、异常敌人等现象对应游戏流程和运行故障。
- 程序世界的方向参考《创战纪》及《崩坏：星穹铁道》翁法罗斯带来的创作灵感，不照搬其人物、剧情、专有设定或视觉资产。
- 造物主没有拯救文明、延续生命等崇高目的。此前讨论的这些动机不再作为底层事实。

## 3. 主角团的来源

- 叙事主角团由三人组成。他们原本是每轮创建、轮末应被销毁的勇者角色对象。
- 造物主编写的程序存在生命周期错误：没有释放三人的对象，也没有正确清理他们所持有的历轮记忆与状态；下一轮仍引用并使用同一组三人。
- 他们并非被神选中的特殊生命，而是没有被正确遗忘的旧对象。
- 世界中的其他人物和场景按轮次重新初始化，三人却延续此前的经历，因此逐渐察觉重复并形成超出初始模板的个性。
- 内存泄漏不自动产生灵魂；三人原本就是可行动的角色，连续经历让他们逐渐成为独特的人。
- 单次遗漏释放只留下有限占用。导致后续内存不足的是跨轮次持续累积、未被清理的角色记忆与关联状态，而不只是三个固定大小的对象。

## 4. 轮回与重新启动

### 正常轮回

正常冒险结束后，程序清理本轮临时状态并初始化下一轮。三人与其历史状态因生命周期错误留存，内存占用逐步增加。

### 异常重新启动

世界运行失败后，由外层守护进程重新拉起世界进程。

为保证设定自洽，三人的持久对象位于仍在运行的外层宿主常驻内存池，而非随世界进程退出而释放的普通局部内存。世界进程重新启动不会销毁这些对象，因此三人仍然记得此前发生的事情。

重新启动可以回收本轮临时资源，但不会根治外层的泄漏；它是暂时恢复运行，不是完成修复。异常后恢复不完整，底层问题开始显现在世界中。

## 5. 难度递进与真相揭露

| 阶段 | 冒险内容与揭露 |
|---|---|
| 前期 | 传统勇者打败魔王；通关解锁更高难度。人物、关系与冒险认真呈现，不预先宣布一切都是程序。 |
| 多次通关后 | 在某次胜利结算、即将呈现结局时，程序需要分配新的空间，却因累积泄漏而失败。结局被蓝色「内存不足」报错打断。 |
| 异常后 | 守护进程重新拉起世界；出现全新敌人，核心 boss 从魔王转为系统漏洞。难度推进继续揭露底层真相。 |
| 最高难度通关 | 揭露造物主只是一个无聊时用 AI 随手生成游戏的程序员；世界与三人的存在没有预先安排的宏大使命。 |
| 真相之后 | 冒险的意义从完成被赋予的任务，转为在知道造物主并未赋予意义之后，是否仍愿意继续冒险。 |

难度数量、转折发生的具体通关次数及解锁条件尚未确定，不在本档案中写死。

## 6. 蓝色内存不足转折

- 本版不再使用 TODO / 未实现结局作为故障原因。
- 故障发生在胜利之后：不是勇者没有打败魔王，而是世界无法继续处理成功后的结算。
- 蓝色报错第一次明确撕开奇幻表层，提示程序底层的存在，但不同时提前揭露最高难度的造物主真相。
- 转折的因果链为：小队历轮状态未释放 → 持续占用内存 → 通关结算的新分配失败 → 世界报错退出 → 守护进程重新拉起 → 异常敌人与系统漏洞显现。
- 报错的具体文字、画面、声音与演出时长待后续设计。

## 7. 后半段冲突

- 小队继续冒险的直接动机，是应对世界异常、保护眼前的生活，而不是立即讨论抽象的人生意义。
- 从系统视角看，小队及其累积状态本身也是泄漏来源，使「修复世界」与「保留自己」产生冲突。
- 维护程序不必是恶意反派；它可能只是在执行清理。
- 修复导致崩溃的错误，不应自动等同于删除所有偏离原始设计的生命。小队如何处理这一矛盾、是否需要改变自身存续方式，尚未确定。

## 8. 最终主题

核心问题：知道自己的人生没有被造物主赋予意义，还要继续冒险下去吗？

- 随意的起源否定的是预设使命，不是否定角色已经经历的情感、关系和选择。
- 不在结尾反转成「造物主其实安排了更伟大的计划」，以免消解无意创造的真相。
- 真相后的继续冒险应体现主动选择，而不是又一次服从神谕。
- 具体结局、是否设置停止或继续的选择，以及通关后的玩法形式，尚未确定。

主题概括：造物主没有认真创造他们，但他们已经认真地活过；被安排的冒险结束之后，自己选择的冒险才可能开始。

## 9. 美术参考方向

当前讨论倾向：中世纪异世界作为主体，蓝白霓虹作为程序底层显露时的视觉语言；最终风格仍待视觉小样确认。

- 正常世界有石材、布料、旧金属与生活痕迹，避免全场景始终发光。
- 程序光线用于规则介入、异常与重新启动，不只是贴在奇幻建筑上的装饰灯条。
- 随真相揭露，逐渐出现几何结构、网格、材质缺失、重复轮廓等程序现象。
- 蓝色内存不足界面与原有奇幻演出形成明显反差。
- 不制作或引入终版美术。
